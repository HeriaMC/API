# 🚀 API

Old infrastructure previously used on the now closed HeriaMC server.

## New servers using it:

- 🌍 **FanCraft** https://www.fancraft.eu
 (300 players everyday)

## ✨ Features:

- 🧠 **Smart data management**: one-click data handlers on local, cache, or persistent level.
- 🚀 **On-demand servers**: fast and reliable servers using the Linux "screen" feature (4–5s to start a 1.8 server).
- 🎯 **Server smart queues**: dynamic server creation and automatic joins based on player load.
- 💬 **Messaging system**: fast cross-server messaging powered by Redis.
- 🧩 **Bukkit interaction APIs**: easily manage inventories, commands, nametags, bossbars, and scoreboards.
- 🛡️ **Moderation tools**: moderate your server with reports, sanctions, moderation mode, vanish, history GUI, and more.
- 👑 **VIP features**: give donators exclusive perks like announcements, custom prefixes, custom nicknames, and more.
- 🤝 **Community features**: built-in groups and friends system.
